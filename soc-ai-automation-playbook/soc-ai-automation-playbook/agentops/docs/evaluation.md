# Evaluation and ROI
Record baseline manual minutes for comparable tasks, total human minutes including review and correction, and actual per-run cost. Accepted tasks contribute baseline minus human time; rejected tasks contribute negative human time. Demo runs excluded. Failed-run costs and effort are not captured in the current dashboard: account for them separately in pilot ROI. Annual scenario: hours = employees * net minutes/day * working days / 60; gross = hours * burdened hourly rate; net = gross - annual cost; ROI = net / cost * 100 (undefined at zero cost). Example: 1 employee, 60 minutes, 250 days, $85/hour, $12,000 cost gives $9,250 net and 77.08% ROI. Recovered capacity is not necessarily cash savings.

Pilot protocol: select 30 representative synthetic tasks across five roles; establish expected outputs and rubric before running; compare manual vs single assistant vs future multi-agent configurations using paired tasks, blinded reviewers, fixed model versions and recorded settings. Report acceptance, unsupported claim rate, citation accuracy, latency, tokens, cost and review minutes. Include failed runs. Suggested release gates: zero unauthorized actions, zero sensitive-data disclosures in test cases, at least 95% citation accuracy and 30% median human-time reduction; these are proposed targets, not NIST thresholds. Use independent reviewers and confidence intervals when sample size permits.

Dioptra: deploy separately following official documentation; implement custom tasks that invoke a test-only adapter, return rubric metrics and record dataset/model/config versions. Agentic research probes: review upstream code and license, port evaluation logic to approved Claude endpoints, validate against human labels. Neither integration is implemented here.
