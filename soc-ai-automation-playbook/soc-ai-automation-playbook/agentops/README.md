# Agent Operations Center (v0.2)

A local, synthetic-data-only pilot for AI task approval, human review, tamper-evident audit and measured ROI. Start with `docs/install.md`. Demo mode needs no AI subscription. Claude mode makes one Anthropic Messages API call per task, with no tools.

This is not an enterprise production deployment and is not NIST-certified. See `docs/governance.md` for what is and is not enforced, and `../docs/security-scan-report.md` for the v0.1 to v0.2 security changes.
